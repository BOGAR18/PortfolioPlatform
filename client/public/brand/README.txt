Letakkan file logo Anda di folder ini dengan nama persis:
  logo.png      -> logo yang tampil di navbar, footer, dan panel admin (disarankan PNG/SVG transparan, tinggi ±128px)
  favicon.png   -> ikon di tab browser (disarankan persegi 512x512 px)
Setelah file diletakkan, jalankan ulang: npm run build

profile.jpg  -> foto yang tampil di kartu kontak (disarankan rasio 4:5, minimal 800px tinggi)
